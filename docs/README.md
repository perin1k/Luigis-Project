# Find the right guide

## Using Luigi’s Pizza

These guides are written for people using or running the restaurant. No programming
knowledge is needed.

| I need to… | Read |
| --- | --- |
| Place/track an order, prepare orders, manage the menu or view sales | [Using your website](handoff.md) |
| Create or recover a customer account and find my orders | [Your customer account](customer-account-help.md) |
| Sign in, accept an invitation, set up phone codes or recover access | [Staff sign-in help](account-help.md) |
| Correct customer details or handle an information request | [Customer information requests](customer-information-help.md) |
| Demonstrate the website or review the instructions | [Demonstration guide](review-access-plan.md) |

For website outages, start with **If the website is unavailable** in Using your
website. Restaurant staff do not need server commands to use the application.

## Building, hosting or reviewing the software

The following material is for developers, technical website support or project
reviewers. It is not required reading for customers or restaurant staff. If you
are an owner arranging technical support, give your support person the links below.

- [Developer and hosting handoff](developer-handoff.md): setup, architecture,
  configuration, accounts, deployment, recovery and costs.
- [Deployment runbook](deployment-runbook.md), [maintenance](maintenance-continuity.md),
  [monitoring](operations-monitoring.md) and [private key custody](secret-custody.md).
- [Third-party inventory](third-party-notices.md): developer notice/license review.
- Other design, policy, data, security and integration records in this directory
  explain implementation decisions. Their staff-facing instructions are summarized
  in the guides above. Files under `verification/` are engineering evidence/history,
  not user manuals. Historical results do not imply current final acceptance.

Developer references may contain programming terms and commands. End-user guides
should explain necessary unfamiliar words and use the actual names shown on screen.
Do not give a customer or staff member a technical record as their everyday manual.
