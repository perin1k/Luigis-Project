# Correcting or sharing customer information

For managers and the owner. Employees should refer these requests to a manager.
The current website is for practice: use made-up details, not real customer data.

## Check who is asking

Confirm the person’s identity in person or through a contact method the restaurant
already knows belongs to them. A name or order number alone is not enough. Do not
ask for a password, full card number or phone security code. If you are unsure,
stop and ask the owner. Do not send information to a newly supplied address simply
because the requester asks you to.

## Correct a name, phone number or email

1. Sign in as Admin or Owner and open **Order queue**.
2. Open the correct order. Under **Decision**, choose **Customer privacy review**,
   then select **Open privacy review**.
3. Read the instructions and check **I verified the requester and reviewed this order**
   only after completing that check.
4. Correct **Customer name**, **Phone number** or **Email address**, then select
   **Save contact correction**. Carry-out still needs a phone; dine-in needs a phone
   or email. Check the success message.

If saving is interrupted, reload the page to see what was saved before trying
again. If someone else changed the order, reload and review the current details.
This changes contact details only, not purchased prices, cancellation or refund status.

## Show a limited information copy

After verifying the requester and checking the review box, select **Show limited
data copy**. Read the displayed copy before any approved private handoff. It includes
the saved contact details, order reference, service/status and purchased items.
Unsaved form changes are not part of that saved copy.

The website does not send, download or automatically copy it for you. Do not post
it in Trello, GitHub, public chat or a screenshot. Select **Hide data copy** when
finished, and sign out on shared computers. The restaurant must protect any copy
it separately chooses to give someone; hiding the screen cannot erase such a copy.

## Other requests

For a lost private tracking link, ask the owner/manager to review the request.
Do not reveal a link based only on a name or order number. An approved replacement
turns off the old link.

The website removes identifying order information after its retention period:
normally seven days after the final outcome, longer while a cancellation/refund
case remains unresolved. It keeps order history without those identifying details.
This is not a promise that every external copy is erased. Refer deletion, unusual
requests or suspected exposure to the owner; do not edit technical files yourself.
